# Loadsheading-App
A simple mobile application built with MIT App Inventor to help users track scheduled power outages in real-time. The app provides timely alerts to users and allows an admin to securely log in and update the load-shedding schedule using cloud storage for authentication.
Features

    Real-time load shedding alerts.

    View upcoming outage schedules.

    Admin login to manage and update schedules (using cloud storage for authentication).

    User-friendly mobile interface.

    Built using MIT App Inventor.

Tools & Technologies

    MIT App Inventor

    Cloud Storage (for authentication and schedule management)

    Mobile notifications

How It Works

    Users can check daily or weekly load-shedding schedules via the app.

    Admins log in with their credentials (verified via cloud storage) to add, edit, or delete schedules.

    Users receive real-time alerts and reminders based on the updated schedule.

Download & Installation

The app is currently available as an APK file.
